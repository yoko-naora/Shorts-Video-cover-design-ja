# Instagram用10構図テンプレート

以下はInstagram向けの詳細テンプレート。選択した構図だけを読み、他の構図を混ぜない。

## 1. ダークグラデーション

```text
[4:5 縦構図 / 9:16 縦構図]。

参照画像1の[性別]の顔立ちを保ち、本人らしさを維持する。半身で、人物を[位置]に置く。

[具体的な表情]。[身体の位置と姿勢]。[右手と左手の位置、指先の動作]。
[人物と主役の間に起きている具体的な行動]。
[主役の形、内容、大きさ、動き、質感]。

参照画像2/3がある場合は、[画像番号]を[位置と見せ方]として使う。

大きな日本語タイトル「[短い大字タイトル]」を人物の背後に重ねる。[書体]、[文字色と縁取り]。人物や主役が文字の一部を隠し、奥行きを作る。

背景：[深い色から深い色への具体的なグラデーション]。前景には[テーマに合う小物]を少数だけ置く。小物は文字の端を一部だけ遮る。

すべての重要要素を安全領域内に置き、浮遊物には控えめな影を付ける。高彩度でも安っぽい発光や過剰な粒子は避ける。
```

## 2. フラットカラー

人物を切り抜き、単色または2色の背景に置く。人物は画面の25〜40%、タイトルは余白側に置く。小物は2〜3個に限定し、輪郭と色を明確に書く。

## 3. プロダクト / UI主役

```text
[4:5 縦構図 / 9:16 縦構図]。

参照画像1の[性別]の顔立ちを保ち、半身で体量は約25%。人物を画面[左/右]下に置き、[右手/左手]で主役を指し示す。[具体的な表情]、視線は主役へ向ける。

参照画像2を画面の主役として約60〜70%使う。[UI/商品]を[浮遊カード/大きな画面/人物の隣のパネル]として見せる。[画面のどの部分、どの文字、どの画像、どの進捗表示を明確にするか]を書く。

参照画像3がある場合は、[位置]に[カード/フレーム/背景レイヤー]として置く。実際に配置する素材か、色とレイアウトだけを参考にするかを明記する。

タイトル「[短い大字タイトル]」を主役の[上端/左端/右端]に重ねる。[書体]、[色、縁取り、影]。人物の顔とUIの重要部分を隠さない。

背景は[明るい/中間色]にし、UIを絶対的な主役にする。画面、人物、タイトルは安全領域に収める。
```

## 4. 比較カード

人物を中央または下部に置き、両手で2枚のカードを前方へ差し出す。左カードと右カードの内容、大きさ、前後関係、色、見出しを別々に書く。「変更前/変更後」「悩み/解決」のような短い日本語だけを使う。

## 5. ミニマル余白

背景の60%以上を余白にする。人物は小さく片側または下部に置き、タイトルが唯一の強い視覚要素になる。紙、細線、淡い影を使い、装飾を増やさない。

## 6. ポスターコラージュ

```text
[4:5 縦構図 / 9:16 縦構図]。

参照画像1の顔立ちを保ち、半身で人物を[位置]に置く。[表情]、[胴体の向き]、[両手の具体的な動作]。

前景：[最大の素材または小物]。画面の約[割合]を占め、[位置]に傾けて置く。白い縁、控えめな影、浮遊感を付ける。
中景：人物主体。前景が人物の[肩/腕/腰]を少し遮る。人物の手や視線が前景と関係する。
後景：参照画像3または[背景カード]を[枚数]枚、ぼかして重ねる。紙、写真、線、円、UIの断片を錯落と配置するが、主役より目立たせない。

タイトル「[短い大字タイトル]」を人物と前景の間に重ねる。[書体]、[色、縁取り、影]。タイトルも複数レイヤーと遮り合う。

暖色/寒色など選択した背景色を使い、前景・中景・後景の奥行きを明確にする。すべての重要要素を安全領域に置く。
```

## 7. 人物片側・余白

人物を画面の左または右に小さく置き、反対側をタイトル用の広い余白にする。人物の手や視線をタイトルへ向ける。背景は淡色または指定色、タイトルは大きくても単語数を増やさない。

## 8. 後ろ姿

表情の質問を省略する。人物を背中または斜め後ろから描き、視線の先に[画面/光/街/アバターの象徴]を置く。顔を正面に戻さない。タイトルは余白側に置き、後ろ姿と対象の距離感を具体化する。

## 9. 部分クローズアップ

手、半顔、横顔、肩から下など、見せる範囲を明記する。商品・画面・タイトルが主役で、人物は補助にする。手に持つ物の大きさ、指の位置、画面との距離、視線の方向を具体的に書く。

## 10. 正面アイコンタクト

人物を中央に置き、目線をカメラに合わせる。タイトルを顔の上、左右、または肩の周囲に配置する。顔、タイトル、背景の余白が競合しないようにし、文字が目や口を隠さない。ブランド名はラテン文字の原表記を保つ。

## 文字と品質の共通指示

- 日本語タイトルは引用符で囲み、文字列を一字一句そのまま描く。
- 漢字・平仮名・片仮名・ラテン文字を意味に応じて自然に使う。
- 画像モデルが日本語を正確に描けない場合は、文字を後から組む前提でレイアウトを作る。
- 余分な人物、透かし、文字化け、意味のない日本語、顔の変形、手指の崩れ、UIに隠れる文字を避ける。
