# Shorts-Video-cover-design-ja

日本語のInstagram投稿、カルーセル、Reels表紙を設計するCodex Skillです。

## できること

- 中国語・日本語の記事や台本から、自然な日本語タイトルを作成
- 10種類の構図から内容に合うスタイルを選択
- 人物、UI、商品、動画画面などの複数参考画像に対応
- Feed / カルーセル向け4:5、Reels表紙向け9:16のプロンプトを作成
- 平仮名、片仮名、漢字、ラテン文字を自然に使い分け
- 人物の姿勢、手の動き、素材の占有率、前景・中景・後景、遮り方まで具体化

## インストール

CodexのSkillディレクトリにリポジトリを配置してください。

```text
%USERPROFILE%\.codex\skills\gbro-cover-design-ja
```

## 呼び出し方

```text
$gbro-cover-design-ja を使って、この台本に合う日本語Instagramカバーを設計してください。
```

画像1は人物の顔・本人らしさの参考画像、画像2以降はUI、商品、動画画面、レイアウト参考として扱います。

## 注意

本Skillは画像生成プロンプトを作成します。画像モデルを直接呼び出さず、APIキーも必要ありません。生成後は、日本語タイトル、ブランド名、長音記号、漢字と仮名を逐字確認してください。
